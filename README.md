# Alcohol Tendency Prediction Project

![Python](https://img.shields.io/badge/Python-3.7%2B-blue)
![Machine Learning](https://img.shields.io/badge/Machine-Learning-orange)
![RLMS-HSE](https://img.shields.io/badge/Data-RLMS--HSE-green)

Анализ склонности к алкоголю на основе данных RLMS-HSE с применением машинного обучения и статистических методов.

## 📋 О проекте

Этот проект использует данные 32-й волны Российского мониторинга экономического положения и здоровья населения (RLMS-HSE) для:

- **Прогнозирования** склонности к алкоголю с помощью Machine Learning
- **Выявления** ключевых факторов риска
- **Статистической проверки** гипотез о гендерных различиях
- **Создания** комплексного алкогольного индекса

## 🎯 Ключевые результаты

### 🔬 Основные находки:
- **Мужчины имеют в 4.8 раза более высокие шансы** склонности к алкоголю
- **27.5% мужчин** vs **7.3% женщин** демонстрируют склонность к алкоголю
- **ROC-AUC модели: 0.908** - отличная предсказательная способность
- Все статистические тесты показали **высокую значимость (p < 0.0001)**

### 📊 Модель машинного обучения:
- **Алгоритм**: Random Forest Classifier
- **Точность**: 85%
- **Recall**: 75% для класса "склонность к алкоголю"
- **Precision**: 53% для класса "склонность к алкоголю"

## 📊 Методология

### 1. Предобработка данных
- Очистка от некорректных значений (88888888, 99999996-99999999)
- Замена пропусков
- Кодирование категориальных переменных

### 2. Feature Engineering
Создан комплексный алкогольный индекс на основе:
- **Прямых маркеров** употребления алкоголя
- **Демографических** факторов (пол, возраст)
- **Поведенческих** паттернов (курение, склонность к риску)
- **Личностных** характеристик

### 3. Моделирование
- **Random Forest** для классификации
- Стратифицированное разделение на train/test (70/30)
- Балансировка классов
- Оценка feature importance

### 4. Статистический анализ
- **Z-тест** для разницы пропорций
- **Хи-квадрат** тест независимости
- **T-тест** для сравнения средних
- **Отношение шансов** (Odds Ratio)

## 📈 Ключевые переменные

### Целевая переменная
- `alcohol_tendency_comprehensive` - бинарный показатель склонности к алкоголю

### Признаки модели
- **Демография**: возраст, пол, образование
- **Личностные характеристики**: 22 черты из Big Five
- **Рисковое поведение**: общая склонность к риску, финансовый риск, etc.
- **Здоровье**: самооценка здоровья, курение

## 🔍 Научная ценность

### Подтвержденные гипотезы:
1. **Гендерные различия** - мужчины значительно более склонны к алкоголю
2. **Валидность комплексного индекса** - индекс коррелирует с реальным поведением
3. **Многомерность факторов** - склонность определяется комплексом признаков

### Практическое применение:
