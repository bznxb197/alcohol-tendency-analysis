# Alcohol Tendency Screening

![Python](https://img.shields.io/badge/Python-3.12-blue)
![LightGBM](https://img.shields.io/badge/Model-LightGBM-orange)
![RLMS-HSE](https://img.shields.io/badge/Data-RLMS--HSE-green)
![Docker](https://img.shields.io/badge/Docker-Container-blue)

Скрининг поведенческой склонности к рискованному употреблению алкоголя по данным RLMS-HSE (32-я волна): статистический анализ, сравнение ML-моделей с честной схемой валидации, калибровка, интерпретация и веб-сервис.

**Онлайн-версия:** [alcohol-tendency-analysis-123.onrender.com](https://alcohol-tendency-analysis-123.onrender.com/)

## Ключевые результаты

| | Значение |
|---|---|
| Модель | LightGBM + sigmoid-калибровка |
| ROC-AUC (hold-out) | **0.746** [0.715; 0.775] |
| PR-AUC (hold-out) | **0.336** [0.280; 0.399], бейзлайн 0.131 |
| Recall / Precision при пороге скрининга | **0.82** / **0.21** |
| Brier score | 0.103 |

В квадратных скобках — 95% бутстреп-интервалы на отложенной выборке (n = 1 851, 243 позитива).

## Данные и целевая переменная

**RLMS-HSE, 32-я волна.** Из 11 820 строк в анализ вошли **9 252 взрослых (18+)**:

- исключены 2 220 человек младше 18 лет: взрослую анкету они не заполняют;
- исключены 51 взрослый без содержательного ответа на вопросы об употреблении алкоголя;
- исключены 51 пивший за последние 30 дней с пропусками в поведенческих маркерах;
- исключены 246 респондентов, не ответивших на личностный блок (пропущено больше половины из 22 вопросов).

**Целевая переменная** — бинарный индикатор высокого поведенческого риска. Он строится по взвешенному индексу маркеров: употребление за последние 30 дней, на работе, без еды, до еды, на улице, в барах, в гостях. Положительный класс — индекс > 5, это **13.2%** выборки.

Вопросы о маркерах в RLMS задают не всем: непьющим и не пившим за последние 30 дней их пропускают по логике анкеты. Такие ответы восстановлены как «нет», а не заполнены модой. Компоненты таргета в признаки не входят.

**Признаки (33):** возраст, пол, образование; 22 личностные черты (шкала 1–4); склонность к риску в разных сферах (0–10) и факт вождения; самооценка здоровья; курение.

- Ответы «затрудняюсь ответить» в шкалах риска связаны с таргетом. Они импутируются медианой с бинарным индикатором пропуска.
- Ответ «не относится» в вопросе о риске за рулём означает «не водит» и выделен в отдельный признак `drives`.

## Статистический анализ: пол

| | Мужчины | Женщины |
|---|---|---|
| Доля группы риска | 19.2% | 9.1% |

- Различие значимо: z-тест, χ² и t-тест дают p < 0.0001.
- **Сырой OR = 2.36.** После поправки на остальные признаки в логистической регрессии **скорректированный OR = 1.68** [1.41; 2.00].
- На логарифмической шкале шансов примерно 40% эффекта пола объясняются сопутствующими факторами, прежде всего курением.

## Сравнение моделей

Схема валидации:

- стратифицированный hold-out 20%, который не использовался до финальной оценки;
- на оставшихся 80% — стратифицированная 5-fold CV с одинаковыми фолдами для всех моделей;
- весь препроцессинг (импутация, скейлинг) живёт внутри `Pipeline` и обучается только на train-части фолда.

| Модель | ROC-AUC | PR-AUC | Precision при Recall ≥ 0.85 |
|---|---|---|---|
| **LightGBM (tuned)** | **0.771 ± 0.015** | **0.347 ± 0.016** | 0.216 ± 0.013 |
| RandomForest | 0.769 ± 0.017 | 0.341 ± 0.019 | 0.217 ± 0.019 |
| Bagging | 0.761 ± 0.014 | 0.333 ± 0.015 | 0.211 ± 0.013 |
| CatBoost | 0.761 ± 0.020 | 0.331 ± 0.016 | 0.209 ± 0.018 |
| LogReg L1 | 0.736 ± 0.014 | 0.287 ± 0.011 | 0.201 ± 0.013 |
| LogReg L2 | 0.735 ± 0.014 | 0.286 ± 0.010 | 0.198 ± 0.012 |

*Mean ± std по 5 фолдам. Бейзлайн PR-AUC равен доле класса, 0.132.*

**Древесные ансамбли сопоставимы:** различия меньше разброса по фолдам. LightGBM выбран как лучший по среднему PR-AUC: в парном сравнении на одних и тех же фолдах он обходит RandomForest в 4 из 5.

**Логистическая регрессия отстаёт стабильно.** Основная причина — нелинейный эффект возраста. Доля группы риска по возрастам:

| 18–29 | 30–44 | 45–59 | 60+ |
|---|---|---|---|
| 13.6% | 20.6% | 16.7% | 5.5% |

Линейная модель такой пик в середине не улавливает.

Тюнинг: `RandomizedSearchCV`, 25 итераций, метрика PR-AUC.

## Калибровка и порог

- Веса классов (`scale_pos_weight ≈ 6.6`) завышают вероятности: без калибровки средняя предсказанная вероятность 0.357 при доле класса 0.132.
- Sigmoid-калибровка (`CalibratedClassifierCV`, внутренняя CV) возвращает среднюю вероятность к 0.132 и снижает Brier с 0.166 до 0.101. Isotonic дала тот же Brier, но хуже LogLoss.
- Порог и зоны выбраны **по откалиброванным OOF-предсказаниям**, а не по тесту:
  - порог скрининга — максимальная precision при recall ≥ 0.85, **p ≥ 0.092**;
  - порог высокого риска — при recall ≥ 0.5, **p ≥ 0.224**.

| Зона | Доля выборки | Доля группы риска (CV) | Доля группы риска (hold-out) |
|---|---|---|---|
| Ниже среднего | 47% | 4.2% | 4.9% |
| На уровне среднего | 33% | 13.9% | 15.4% |
| Выше среднего | 20% | 33.7% | 29.2% |

**Цена скрининга:** чтобы найти около 85% группы риска, нужно отметить около 53% опрошенных. Модель надёжнее всего **исключает** риск: в нижней зоне, а это почти половина выборки, к группе риска относятся менее 5%. Максимальная откалиброванная вероятность около 0.4: по личности, склонности к риску и демографии алкогольное поведение предсказывается лишь умеренно.

## Интерпретация

SHAP (LightGBM) и скорректированные OR (логистическая регрессия) независимо выделяют одни и те же главные факторы. Корреляция рангов важности по Спирмену **ρ = 0.71** (p < 0.001).

| Фактор | Ранг SHAP | Ранг в логите | OR [95% CI] |
|---|---|---|---|
| Возраст | 1 | 2 | 0.98 за год (нелинейно, пик в 30–44) |
| Курение | 2 | 1 | 2.36 [2.02; 2.76] |
| Пол (М) | 3 | 3 | 1.68 [1.41; 2.00] |
| Общая склонность к риску | 4 | 4 | 1.10 за балл |

Личностные черты дают слабый, но согласованный сигнал:

- экстраверсия связана с более высоким риском: разговорчивость OR 1.18, сдержанность в мнениях OR 0.83;
- ориентация на долгосрочные цели и будущее — с более низким: OR 0.86 и 0.87.

Коэффициенты отдельных черт одного фактора интерпретировать не следует: черты коррелируют между собой.

## Качество по сегментам

Порог один: абсолютный откалиброванный риск ≥ 9.2%. Поэтому при разной базовой доле класса recall различается по группам. Ниже — данные 5-fold CV на train; на hold-out результаты воспроизводятся.

| Сегмент | Доля класса | ROC-AUC [95% CI] | Recall | Hold-out recall |
|---|---|---|---|---|
| Женщины | 8.8% | 0.76 [0.73; 0.78] | 0.73 | 0.74 |
| Мужчины | 19.6% | 0.73 [0.71; 0.75] | 0.93 | 0.89 |
| 18–29 | 13.6% | 0.73 [0.67; 0.77] | 0.89 | 0.84 |
| 30–44 | 20.6% | 0.73 [0.71; 0.76] | 0.95 | 0.92 |
| 45–59 | 16.7% | 0.69 [0.66; 0.72] | 0.86 | 0.89 |
| 60+ | 5.5% | 0.77 [0.72; 0.81] | 0.54 | 0.50 |
| Курящие | 25.1% | 0.67 [0.64; 0.70] | 0.99 | — |
| Некурящие | 9.3% | 0.76 [0.74; 0.78] | 0.73 | — |

- **Женщины и люди 60+.** Ранжирование внутри этих групп хорошее, но из-за низкой базовой доли многие случаи не дотягивают до общего порога. Recall 0.73 и 0.54.
- **Курящие.** Модель почти не добавляет информации к самому факту курения: AUC 0.67, precision внутри группы 0.27 при базовой доле 0.25.
- Единый порог выбран сознательно. Групповые пороги на малых подгруппах (например, ~150 позитивов у 60+) были бы нестабильны.

## Веб-сервис

- Анкета из 33 вопросов → вероятность и зона риска с пояснением, какая доля людей с похожими ответами относится к группе риска.
- Сервис загружает **весь пайплайн** из `model.joblib`: препроцессинг, модель, калибровку, пороги. Препроцессинг вынесен в `preprocessing.py`, общий для ноутбука и сервера, поэтому модель в проде получает признаки в той же кодировке, что и при обучении.
- HTTP-сервер на сокетах без фреймворков, валидация формы, Docker, деплой на Render.

## Запуск

```bash
git clone https://github.com/bznxb197/alcohol-tendency-analysis.git
cd alcohol-tendency-analysis
python3.12 -m venv .venv && source .venv/bin/activate

# Веб-сервис
pip install -r requirements.txt
python alcohol_screening_server.py          # http://localhost:10000

# Ноутбук с анализом (нужен файл данных RLMS в data/)
pip install -r requirements-dev.txt
jupyter notebook alcohol_analysis.ipynb
```

```bash
docker build -t alcohol-screening .
docker run -p 10000:10000 alcohol-screening   # http://localhost:10000
```

## Ограничения

- **Кросс-секционные данные:** модель описывает ассоциации, а не причинно-следственные связи.
- **Таргет:** индекс построен на эвристических весах маркеров, а не на валидированной клинической шкале (например, AUDIT).
- **Веса выборки:** оценки посчитаны без весов RLMS, поэтому доли и OR описывают выборку, а не население России.
- **Неравный recall:** из-за единого порога recall ниже у женщин и людей 60+.
- **Курящие:** внутри этой группы модель слабо различает людей.
- **Не диагностика:** модель — инструмент предварительного скрининга и не заменяет консультацию специалиста.
